# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview
The **HR Analytics Dashboard** is an interactive Power BI project designed to help organizations analyze workforce data, monitor employee attrition, and support HR decision-making. The dashboard provides valuable insights into employee demographics, department-wise distribution, salary trends, job satisfaction, and attrition patterns.

This project demonstrates data visualization, business intelligence, and HR analytics skills using Microsoft Power BI.

## 🎯 Objectives
- Monitor employee attrition and retention.
- Analyze workforce demographics.
- Identify departments with high attrition.
- Understand the relationship between salary, experience, and employee turnover.
- Analyze employee satisfaction across job roles.
- Support HR teams with data-driven decisions.

## 📈 Dashboard Features
 ### KPI Cards
 - 👥 Total Employees
 - ✅ Active Employees
 - ⚠️ Attrition Count
 - 📉 Attrition Rate (%)
 - 🎂 Average Employee Age
 - 💼 Average Experience

 ### Interactive Filters
 - Department Filter
 - Age Group Filter

 ### Visualizations
 - Department-wise Attrition (Donut Chart)
 - Attrition by Salary Slab (Bar Chart)
 - Job Role vs Satisfaction Matrix
 - Age Group Distribution
 - Gender-wise Attrition
 - Attrition Trend by Experience
 - Department-wise Employee Count

## 🛠 Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- CSV Dataset

## 📊 Key Insights
